GitHub 업로드
1. 압축을 풀어 6개 파일을 모두 저장합니다.
2. GitHub에서 새 저장소 csat-study-new의 Code 화면으로 이동합니다.
3. Add file → Upload files를 누릅니다.
4. 압축을 푼 6개 파일을 저장소 최상위(root)에 업로드합니다.
5. 기존 파일이 있으면 같은 이름의 파일을 교체하고 Commit changes를 누릅니다.
6. Settings → Pages에서 Deploy from a branch / main / /(root)를 선택하고 저장합니다.
7. Actions에서 가장 최근 Pages 배포가 초록색 완료인지 확인합니다.

이번 버전
- 첨부한 디자인 참고 이미지와 같은 좌측 메뉴 + 상단 검색/D-day + 7일 주간 카드 + 오늘의 학습/주간 현황 구성
- 두 사이트의 색상, 글꼴, 메뉴 디자인 통일
- 주간 일정 재배분은 월~목 ET/EP1/EP2 중 공부하지 못한 시간을 선택해 등록
- 재배분 내역은 금요일/주말 카드에 표시하고, 남은 분량은 다음 주 이월로 표시
- 이유 입력 없음
- 브라우저에 저장된 체크 상태와 재배분 기록은 같은 기기/브라우저에 보관됨
